# JDBC Employee Management System

## Description
This project demonstrates CRUD operations using Java JDBC and MySQL.

## Technologies Used
- Java
- JDBC
- MySQL
- Maven
- IntelliJ IDEA

## CRUD Operations
- Create - Insert employee
- Read - Display employee
- Update - Update employee details
- Delete - Delete employee

## Database
MySQL database is used to store employee information.

## How to Run
1. Install JDK.
2. Install MySQL.
3. Configure the database connection.
4. Run the Main.java file.
